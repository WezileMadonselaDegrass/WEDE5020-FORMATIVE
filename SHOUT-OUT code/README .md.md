## Project Overview

**SHOUT OUT** is a fictional premium cybersecurity retail and services company operating in South Africa. The organisation specialises in providing luxury digital security solutions for modern families, with locations in Sandton, Zwartkop and Midstream.

This website serves as the Portfolio of Evidence (PoE) for a web development assignment at IIE/Rosebank College, demonstrating foundational skills in HTML5, CSS3 and JavaScript.

**Tagline:** *SIC PARVIS MAGNA* ("Great things from small beginnings")

---

## Organisation

SHOUT OUT was created around the idea that modern families deserve premium protection for their increasingly digital lives. The organisation combines luxury service with sophisticated security solutions, ensuring that every member of the household can navigate the digital world with confidence and peace of mind.

**Brand Values:**
- Luxury
- Trust
- Security
- Privacy
- Technology
- Family Protection
- Professionalism
- Exclusivity

## Accessibility

This website implements the following accessibility best practices:

| Practice | Implementation |
|----------|----------------|
| Semantic HTML5 | Proper use of `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` |
| Heading hierarchy | H1 → H2 → H3 structure maintained |
| Form labels | All form inputs have associated `<label>` elements |
| Accessible buttons | Buttons have descriptive text and keyboard support |
| Keyboard navigation | All interactive elements are keyboard accessible |
| Visible focus states | Clear focus indicators for keyboard users |
| Alt text | Descriptive alt text on all images |
| Colour contrast | Sufficient contrast between text and backgrounds |
| ARIA attributes | Used where necessary for enhanced accessibility |
| Reading order | Logical content order matches visual layout |
| Reduced motion | `prefers-reduced-motion` media query support |
